# 钉钉日志集成

先读取 [钉钉官方 API 能力门禁](../../shared/dingtalk-official-api-gate.md)。默认“日报”已实测支持：日期用 `type=5`、`contentType=origin`，文本用 `type=1`、`contentType=markdown`，无内容的图片和附件完全省略。字段数组固定为日期、今日完成工作、近期需完成工作、公司产品、客户反馈、市场竞争信息、需协调工作。

该结构与官方接口页的全文本限制不完全一致，只作为当前 DWS v1.0.66 和服务端的实测兼容行为。提交必须取得 `reportId` 并回读日期、正文和顺序；失败时停止，不自动换参重试。

日志接收人是用户独立维护的工作流配置，可能包含一人或多人；稳定 userId 保存于工作流配置。模板初始化和更新不得从最近日志推断接收人，也不得重置用户已有列表。更换组织或增删接收人时必须重新确认。

首次模板配置默认推荐并展示“日报”（ID `14eade35f619cdbcee39df04266a2811`）及真实字段和其它候选。用户未选择过模板时使用该模板；用户自行选择其它模板后永久保留选择，不再自动改回。

本次未提供“近期需完成工作”时，调用 `report +report-latest --keyword <当前模板名>` 取得最近一次同模板日志，仅提取键名完全等于“近期需完成工作”的非空字段。该历史值是预览默认值，不是用户本次输入；必须在预览中标明来源。
