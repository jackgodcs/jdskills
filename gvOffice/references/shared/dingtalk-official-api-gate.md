# 钉钉官方 API 能力门禁

涉及钉钉工作流的能力评估、开发、外部写入或故障归因时，先查阅 [服务端 API 调用指南](https://open.dingtalk.com/document/development/server-api-calling-guide)、对应产品概述或集成方案和本次实际调用的具体接口页。必须确认接口、应用类型、权限、认证、参数类型、业务限制和成功响应条件。

DWS 仅作为执行适配层。官方未明确支持的行为不得猜测为可用；通过受控提交和稳定 ID 回读确认的行为可以标记为“实测兼容”，但不能表述为官方保证，失败时不得自动换参重试。通用错误码只能证明失败，不能单独证明具体原因。

## 默认日报实测兼容结构

- 默认模板为“日报”，模板 ID `14eade35f619cdbcee39df04266a2811`。
- 日期使用模板真实 `type=5`、`contentType=origin` 和 `YYYY-MM-DD` 字符串。
- 文本字段使用 `type=1`、`contentType=markdown`。
- `contents` 数组顺序固定为：日期、今日完成工作、近期需完成工作、公司产品、客户反馈、市场竞争信息、需协调工作。服务端已实测按数组顺序保存。
- 图片和附件没有真实内容时必须完全省略；`-`、空字符串和 `null` 均已验证不可用。
- 创建成功必须取得稳定 `reportId`，并回读核对日期、正文和字段顺序。

官方“创建日志”接口页面仍声明模板组件只允许文本类型，因此上述结构只能用于该模板和已验证字段结构。模板 ID或字段变化时停止并重新核查。
